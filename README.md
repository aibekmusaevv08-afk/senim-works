# Senim Digital: портфолио деректері

Бұл қоймада сайттың портфолиосы сақталады: `works.json` және `works/` ішіндегі суреттер.
Файлдарды қолмен өзгертпеңіз, сайттың `/admin/` панелі арқылы басқарыңыз.

Здесь хранится портфолио сайта Senim Digital. Не меняйте файлы вручную, используйте панель `/admin/`.
